一、从哪里打开？三条入口与登录凭证说明

外网、局域网、本机看到的是完全同步的数据（私有仓库 sexymonk/consultbench-3d）。

🔑 登录要填的「凭证」是什么？如何获取（仅需做一次）

第 1 步：确认仓库协作者权限（第一次接入必看）

  1. 先告诉 刘俊圆 你的 GitHub 用户名（刘俊圆在控制台右上角齿轮 →「邀请王瑞麟」输入发送）。
  2. 去你的 GitHub 通知或绑定邮箱，点击 Accept invitation 接受私有仓库 sexymonk/consultbench-3d 邀请。

第 2 步：生成你自己的 GitHub Token（即网页上的“凭证”）

  1. 登录 GitHub，打开 github.com/settings/tokens/new。
  2. Note 填 consultbench-3d，Expiration 选 90 days 或不过期。
  3. 勾选整个 repo 权限组，点底部 Generate token 并复制生成的 ghp_... 令牌。
  4. 打开 云端控制台 粘贴进去、选「王瑞麟」即可（勾选“记住登录状态”后下次免输）。

二、王瑞麟如何在自己电脑上 1 分钟接入并跑通项目？

不需要安装庞大的 PeriDyno C++ 源码或 CUDA 编译工具链，也不拉取几十 GB 的历史轨迹文件。

方式 A：一键引导图形向导（最简单）

从 GitHub Release solver-v2.0-baseline 下载 ConsultBench3D_Partner_Bootstrap.zip 解压到任意文件夹，双击 启动王瑞麟一键接入面板.cmd，填入你的 GitHub Token 后会自动补齐 Git / VC++ 运行库、克隆仓库并下载免编译 3D 求解器包。

方式 B：让你的本地 AI 全自动配好

克隆仓库后，把根目录 ONBOARDING_FOR_AI.md 顶部的那段提示词直接复制给 Cursor / Codex / Antigravity，AI 会自动帮你跑完 cb.py setup --auto-fix、verify --lite 与团队规则确认。

日常怎么跑测试？

  • 平时改代码后：运行 python cb.py verify --lite（0.2 秒全绿即可，不占显卡）。
  • 有 N 卡想跑 3D 仿真：运行 python cb.py run-bench smoke_fsi，自动适配你的盘符路径并跑通 4 场景闭环物理仿真。

五、日常协作怎么配合？（3 个典型场景）

场景 1：进网页先干什么？

看左侧任务栏谁有未读蓝点 → 点进去看「团队规则」有没有提示「待你确认」（点一下知道了）→ 看底部讨论和勾选「步骤」进度 → 在发言框回复进展。

场景 2：怎么定分工、防撞车？

在问题单（如 CB-003）下先用「讨论」商量各自认领部分；标题下方直接点击状态和负责人切换为自己；拍板后的边界用「置顶为规则」发一条 G-xxxx，双方 AI 就都不会违背。

场景 3：刘俊圆在 fairy 改完仿真算法怎么同步？

你无需手动拷贝或编译，只需执行 git pull，若发布了新版免编译求解器，打开本机面板「⚙ 环境与同步」点一次「一键补齐」即自动更新并校验。
